# CYRVIS 桌面伙伴 · 角色概念 01

## 角色方向

面向长期使用个人 agent 的桌面用户。以语音交流、眼神和动作反馈为主，短气泡只展示当前一句。默认停留桌面角落，不持续打开聊天窗口。

陶瓷白圆润外壳、深蓝面罩、蓝色侧耳、短手臂与小脚。胸口用分段 C 呼应品牌；角色素材为可编辑的 SVG，PNG 为透明背景。

## 已交付

- `character-board.png` / `.svg`：整体角色及五种交流状态设计板。
- `robot-{idle,listening,thinking,speaking,working,sleeping}.svg` / `.png`：六个状态；PNG 800 × 960。
- `preview.html`：自包含交互原型，可直接打开；带呼吸、眨眼、切换状态、点击唤醒/休息、拖动、顺序演示，支持减少动态效果系统偏好。
- `preview.template.html`、`build.mjs`：源码，执行 `node design/cyrvis-companion/build.mjs` 重建所有交付。

## 状态和后续接入

| 状态 | 视觉 | 后续事件来源 |
| --- | --- | --- |
| 陪伴 idle | 轻呼吸、偶尔眨眼 | 已唤醒但未讲话 |
| 倾听 listening | 歪头、抬手、侧耳声纹 | 语音开始 |
| 思考 thinking | 抬眼、三个思考点 | 模型处理中 |
| 回应 speaking | 弯眼、挥手、面罩声纹 | 音频播放中 |
| 执行 working | 小任务板、操作手势 | 工具任务运行 |
| 休息 sleeping | 闭眼、慢呼吸 | 用户要求休息 |

建议正式桌面形态：约 120–180px 高的透明悬浮窗口，可拖动并记忆位置；气泡仅在沟通时出现。需要确认时出现简短操作卡；历史和设置从小菜单打开。保持键盘可唤醒、可暂停、可隐藏。语音输入状态需单独清楚呈现，不能仅用角色闭眼来暗示麦克风已关闭。

## 实现边界和验证

当前为角色与交互设计原型，未接麦克风、语音模型或任务执行，也未创建系统级悬浮窗口。演示不请求任何权限。

设计板已渲染并检查，六套 SVG/PNG 已导出；页面在内置浏览器成功加载并呈现状态控制。浏览器会话随后中断，因此拖动和完整播放流程尚未完成浏览器交互验证。脚本语法已通过 Node 检查。
