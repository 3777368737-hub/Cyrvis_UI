## 注视主动提醒

使用方法：开启语音，在眼动面板完成“快速体验AI看屏”，勾选“注视主动提醒”，然后隐藏工作台，看向其他应用中的目标。该选项默认关闭，每次重新开启摄像头后需自行开启。

- 本地检测同一区域持续注视，默认约 4.5 秒，可选 6 秒或 9 秒。触发后发送一张区域截图到 Settings 的视觉模型，读取可见内容；不上传摄像头视频。
- 确认对象后播报描述并询问下一步。例如识别到音乐名称时，提供播放、歌曲信息、封面背景选项；看不清名称时不提供播放。模糊或多个对象无法区分时静默等待。
- 可以回答“播放它”“介绍一下”“讲讲封面背景”“不用了”，也可以点击面板按钮。只说“好”而存在多个选项时会追问。含新作品名称的请求走原有语音流程，避免错误绑定到旧建议。
- 确认后将作品名称与可见描述补入正常语音 Agent 请求，继续使用已有搜索、快捷工具和 GUI 执行流程。注视本身不执行点击或播放；歌曲信息及背景故事请求要求搜索核对来源，不允许从封面编造故事。
- 忙于说话、等待回答、看屏请求或桌面任务时暂缓触发。注视时长达到后冻结一次截图，允许移开视线或眨眼，返回结果描述“刚才看到的内容”；语音暂时忙碌时排队等待，最多约 25 秒，且截图总年龄不超过 60 秒。关闭共享、手动提问或停止任务仍可取消待播报结果。手动看屏优先于主动识别。
- 提醒至少间隔 60 秒，同一区域 3 分钟、同一对象 5 分钟内不重复提醒。建议 2 分钟后失效；停止任务或拒绝建议会暂缓主动提醒，眼动本身继续运行。

验证：273 项自动化测试通过，7 项原有条件跳过；包含稳定注视触发、关闭/移开时丢弃结果、去重、手动优先、语音选项确认、上下文文本进入实时及级联引擎。真实视觉接口已用独立测试窗口验证结构化识别及选项返回；使用本机实时语音配置的文本请求已收到 65,280 个 PCM 音频采样。摄像头真人精度、实体扬声器可听性和实际音乐应用播放仍需现场体验；这次没有重新调整眼动精度阈值。

## 对象吸附与高亮

眼动面板默认开启“对象吸附（本地识别）”。九点采样后，看向目标附近，黄色边框表示候选，持续约 700ms 后变为绿色锁定框。保留原有平滑，另外使用对象边界、保持区域及持续切换条件，避免视线小幅抖动就切换到旁边。存在难以区分的候选时不强行吸附；看错对象时移开视线再看向目标中央。关闭对象吸附可恢复原先的坐标光标。

- 当前本地对象适配 macOS 主屏幕，适用于桌面和其他应用。先通过只读 Accessibility API 获取按钮、图片、链接、列表项等对象的边界和标签；未暴露对象信息时，使用 Apple Vision 的矩形检测和文字识别补充图像区域。图像区域并不等于已经识别出具体作品。
- 对象扫描由有效眼动样本触发，最多约每 650ms 一次，不上传截图。首次使用会从 `resources/native/gaze-objects.swift` 编译本地辅助程序并缓存到用户数据目录，需要 Xcode 命令行工具；本机已验证可编译。辅助功能不可用时尝试本地图像检测，屏幕录制权限不可用时在面板提示。
- 吸附模式只在锁定后给 AI 与主动提醒提供对象中心、边界和候选标签。主动提醒按对象身份计算持续注视，不会因对象内部的视线变化重新计时。截图优先裁剪该对象并保留附近标题文字；候选标签作为不可信上下文，仍需视觉模型核对。
- 对象列表超过 1.8 秒未刷新、视线超过 800ms 未更新、窗口场景变化或对象明显移动时解除锁定；图像区域身份包含内容指纹，防止同位置替换图片后沿用旧对象。优先捕获目标应用自身窗口的图像，高亮保持显示而不进入检测图像；没有可捕获窗口、必须回退桌面截图时，才短暂移除高亮。
- 高亮窗口独立、透明、穿透鼠标，不移动系统鼠标，不调用任何 AX 操作。停止任务仍不关闭眼动。通过眼动面板隐藏工作台时会恢复桌宠，与关闭主窗口的行为一致。

验证：282 项回归通过，7 项原有条件跳过；前后端类型检查通过。独立原生测试窗口使用合成注视输入，实际读取并锁定了一个 180×180 的语义按钮；对没有语义信息的画布实际检测出约 180×180 的封面区域及 `TEST ALBUM` 标题，并在高亮显示期间维持锁定。该测试验证对象识别和吸附链路，不代表真人眼动准确性或对所有应用的识别覆盖率。

## 修复：锁定封面后没有主动播报

用户截图中的“这片区域的对象还不够明确，暂不主动打扰”来自主动视觉识别的空建议分支，说明当时已经触发识别。旧逻辑把“无法确认作品名称”与“没有可描述的画面”混为低置信度并静默；还在结果为空时将位置写入三分钟去重缓存。

- 视觉输出现在分别判断画面是否可见、对象是否歧义和作品身份置信度。明确可见但不知名称的封面仍描述画面，说明不能确认作品名称，询问是否需要解释；不提供未经确认的播放或背景故事选项。空白或多个目标无法区分时继续保持谨慎。
- 只有实际交给语音的有效建议才应用一分钟成功提醒冷却和已提醒对象缓存。未识别、失败或丢弃的结果不再冒充“已经提醒”；不明确或失败结果约二十秒后重试。面板显示未播报原因，日志记录 trigger、uncertain、discarded、announced、failed 阶段，不记录截图内容。
- 真实接口测试另外复现了 Qwen Audio / Token Plan 新会话没有任何用户消息时，只有 session.update + response.create 会被拒绝。主动播报现在先添加只读文本消息，再请求语音；播报阶段阻止工具执行，正常语音输入或确认后恢复原指令。
- 使用没有任何作品名的独立测试封面，真实视觉模型生成了谨慎描述，随后全新的实时语音会话成功返回 309,120 个 PCM 音频采样；该测试验证接口音频生成，实体设备播放仍需用户确认。
- 对应回归 287 项通过、7 项原有条件跳过；前后端类型检查和构建通过。

## 修复：截图后眼动变化导致请求反复取消

- 截图授权发生在稳定注视达到时长时，之后不因普通移开视线、眨眼或对象识别抖动而中止只读请求。仅显式关闭、手动请求优先、停止任务暂缓或显示器变化取消。
- 结果以“刚才你注视的区域里”开头，语音忙碌或重连时排队，连接准备好再交给 VoiceBrain；超期丢弃并显示原因。日志区分显式取消和真正的 45 秒超时。
- 允许视觉模型提供作品候选，确认前仅作为搜索线索；实测当前模型对用户封面截图返回过错误候选，所以不直接播报候选名称，不给未核实候选提供播放操作。确认后的“核实封面与作品信息”仍使用已有文字搜索/浏览器工具，尚未集成反向图片搜索服务，不等同于真正的以图搜图。
